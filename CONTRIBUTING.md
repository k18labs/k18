# Contributing

## Project license and contribution rights

This project is distributed under Apache-2.0; see [LICENSE](LICENSE). Before opening a pull request, confirm that you wrote the submitted changes or have permission to contribute them, and that they may be distributed under Apache-2.0. Do not submit code, generated files, or third-party material with unclear licensing or ownership.

The repository owners are responsible for maintaining the license and reviewing the project's existing ownership and contribution history. This guide does not establish who owns earlier contributions; resolve that with the relevant contributors before making any ownership claim.

## Changes and review

Keep changes focused and describe their behavior and impact in the pull request. Include the relevant verification results. Security-sensitive changes, including changes to packet parsing, TLS, cryptography, keys, or memory permissions, need review by a maintainer familiar with that area before merge.
